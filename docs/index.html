Быстрый старт

Проект запускается через .NET CLI из папки MelLang. 

cd MelLang

dotnet run -- examples/factorial.mel

Запуск локальной Web IDE:

cd MelLang

dotnet run -- --web

После запуска сервера открыть в браузере:

http://localhost:5000

Пример программы

Факториал на MelLang:

(да_будет_свет

  (еще_посидим factorial
    (омайгад (n)
      (плаки_плаки_или_нормалдаки
        (= n 0)
        1
        (* n (дай_его factorial (- n 1)))
      )
    )
  )

  (скажи_это_сон_да (дай_его factorial 5))

я_помылся)

Web IDE

В проекте есть локальная браузерная IDE. Она предоставляет редактор кода, запуск через интерпретатор, панель вывода, загрузку программ из examples/ и сохранение новых .mel файлов.

GitHub Pages показывает только статическую документацию. Сама Web IDE с F# backend запускается локально командой dotnet run -- --web.
